I coded this so I don't have to waste time calculating where the next caption is to sync with the music.
Might help others aswell so feel free to use this however you want.

This can only make .srt files! (Which is what YouTube uses)

The raw texts file should have lines of text seperated by \n (enter or line break whatever).
A line break indicates that a next section of the caption begins.
raw_texts.txt and synchronized_captions.srt are test samples, replace raw_text.txt with your own texts. 
Any .srt destination, if it exists, will be overwritten.
